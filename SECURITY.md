# Security Policy

## Supported Versions

Sona is currently in early MVP development. Security updates are provided for the latest released version only.

| Version | Supported |
| ------- | --------- |
| 0.1.x   | Yes       |
| < 0.1   | No        |

## Reporting a Vulnerability

If you discover a security vulnerability in Sona, please do not open a public GitHub issue.

Report it privately by using GitHub's private vulnerability reporting feature:

https://github.com/lucifron28/Sona/security/advisories/new

If private vulnerability reporting is unavailable, contact the maintainer privately before disclosing details publicly.

## What To Include

Please include as much detail as possible:

- A clear description of the vulnerability.
- Steps to reproduce the issue.
- The affected Sona version.
- Device model and Android version, if relevant.
- Any logs, screenshots, proof of concept, or sample URLs needed to reproduce the issue.
- Whether the issue affects local files, downloaded media, app storage, playback, networking, or release signing.

## Response Expectations

The maintainer will try to acknowledge valid reports within 7 days.

After a report is reviewed:

- Accepted vulnerabilities will be investigated and fixed as soon as practical.
- A patched release will be published when needed
