## Longer Post

```text
Sona is my Android music player MVP built with Kotlin, Jetpack Compose, Media3, Room, WorkManager, and youtubedl-android.

The current release supports:
- Local audio import without broad storage permissions
- URL audio imports
- Searchable Songs, Artists, and Albums views
- Artist and album drill-down views
- Editable track metadata
- Playlists
- Queue, shuffle, repeat, seek, next, and previous controls
- Light, dark, system, and Dracula themes
- Signed APK releases

The latest work made YouTube imports much faster by avoiding duplicate metadata extraction.

Repo and APK:
https://github.com/lucifron28/Sona

I would appreciate feedback, bug reports, and ideas for the roadmap.
```
